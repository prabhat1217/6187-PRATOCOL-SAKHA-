ડિવાઇસ વચ્ચે ડેટા સિંક (APK + EXE + મોબાઇલ + PC) — Firebase (તમારો પ્રોજેક્ટ: protocol-sakha)

એક વખતનું સેટઅપ (કમ્પ્યુટર પર 10 મિનિટ). પછી ગમે તેટલા ડિવાઇસમાં એક જ ઇમેઇલ-પાસવર્ડ નાખો તો ડેટા સરખો.

ભાગ 1 — Firebase માં (console.firebase.google.com -> પ્રોજેક્ટ "protocol-sakha")
1) Build -> Firestore Database: બનેલું ન હોય તો "Create database" (Production mode).
2) Build -> Authentication -> Get started -> Sign-in method -> "Email/Password" ચાલુ (Enable) કરો.
3) Authentication -> Users -> "Add user": એક ઇમેઇલ અને પાસવર્ડ બનાવો (દા.ત. sakha@gmail.com). આ બધા ડિવાઇસમાં વપરાશે.
   (સાચો ઇમેઇલ હોવો જરૂરી નથી, પણ પાસવર્ડ મજબૂત રાખો.)
4) Firestore Database -> Rules ટેબ -> નીચેનું લખાણ paste કરી "Publish":

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /pdr_local_storage/{doc} {
         allow read, write: if request.auth != null;
       }
     }
   }

   આનાથી ફક્ત લૉગિન કરેલ ડિવાઇસ જ ડેટા વાંચી/લખી શકશે. (જો "Test mode" ના નિયમો હોય તો તે 30 દિવસે બંધ થાય અને ડેટા બધા માટે ખુલ્લો રહે — એટલે ઉપરના નિયમો જરૂર મૂકો.)

ભાગ 2 — દરેક ડિવાઇસમાં (APK અને EXE બંનેમાં)
1) એપ -> મેનુ "ડેટા અને સેટિંગ્સ" -> "☁️ ડિવાઇસ સિંક અને 🔐 OTP".
2) Firebase ખાતાનો ઇમેઇલ + પાસવર્ડ + ડિવાઇસનું નામ -> "કનેક્ટ / સેવ કરો".
3) પહેલા ડિવાઇસમાં (જેમાં ડેટા છે): ક્લાઉડ ખાલી હશે એટલે ડેટા આપોઆપ ઉપર જશે.
4) બીજા/ત્રીજા ડિવાઇસમાં: "ક્લાઉડનો ડેટા અહીં લો" પસંદ કરો. (આ ડિવાઇસનો જૂનો ડેટા સુરક્ષા માટે એપની અંદર નકલ તરીકે સચવાય છે.)

પછી
- એક ડિવાઇસમાં સુધારો -> થોડી સેકન્ડમાં ક્લાઉડ પર -> બીજા ડિવાઇસમાં ~30 સેકન્ડમાં (કે એપ ખોલતા જ) આવે છે અને "નવો ડેટા આવ્યો — હમણાં અપડેટ કરો" સંદેશ દેખાય છે.
- ઇન્ટરનેટ ન હોય તો એપ ચાલે છે; નેટ આવતાં બાકી ફેરફાર આપમેળે જાય છે.
- નીચે "☁️ ✓ સિંક" લીલું = બધું સિંક. નારંગી = ફેરફાર બાકી. લાલ = નેટ/લૉગિન/Rules ની સમસ્યા (સંદેશ સ્ક્રીનમાં લખાય છે).
- ફક્ત ડેટા સિંક થાય છે (કર્મચારી, રજા, રોટેશન, કેલેન્ડર, પરિપત્ર વગેરે). પાસવર્ડ લૉગિન, સ્ક્રીન સેટિંગ અને બેકઅપ નકલો સિંક થતા નથી.
- જૂના ટેસ્ટ વખતના Firestore ના વધારાના ડોક્યુમેન્ટ (લૉગિન કી વગેરે) એપ વાપરતી નથી; ઇચ્છો તો Firebase માંથી કાઢી શકો.

🔐 OTP (Authenticator ઍપ)
- "ડિવાઇસ સિંક અને OTP" સ્ક્રીનમાં "OTP ચાલુ કરો": ફોનમાં Google Authenticator માં સેટઅપ કી નાખો, કોડ ચકાસો. 8 રિકવરી કોડ ત્યારે જ દેખાશે — લખી લો.
- ચાલુ હોય ત્યારે એપ ખોલતી વખતે (12 કલાકે એક વાર) 6 આંકડાનો કોડ પૂછાશે. SMS/ઇન્ટરનેટ જરૂરી નથી.
- બંધ કરવા: એ જ સ્ક્રીનમાં "OTP બંધ કરો" (કોડ કે રિકવરી કોડ જોઈએ). સિંક ચાલુ હોય તો ચાલુ/બંધ બધા ડિવાઇસ પર સરખું.
- પાસવર્ડ લૉગિન અલગ સુવિધા છે ("માસ્ટર સેટિંગ્સ") — તેનું ચાલુ/બંધ દરેક ડિવાઇસ પર જાતે.

ધ્યાન
- બે ડિવાઇસ પર એક જ સમયે એક જ વિભાગ (દા.ત. રજા યાદી) બદલાય તો છેલ્લો સુધારો રહેશે. મહત્વના સુધારા પહેલાં "હમણાં સિંક કરો" દબાવો.
- ડિવાઇસની ઘડિયાળ (તારીખ-સમય) ઓટોમેટિક રાખો.
- Firebase નો ઇમેઇલ/પાસવર્ડ કોઈને આપશો નહીં. મફત પ્લાનની મર્યાદા (દરરોજ 20,000 લખાણ / 50,000 વાંચન) આ ઉપયોગ માટે પૂરતી છે.
